Квадрат числа n — это n² = n · n. Таблица охватывает все двузначные числа: строка — десятки, столбец — единицы.

× 012 345 678 9
ПримерСтрока 4, столбец 7 → 47² = 2209.

Кубы 1–20
20
значений

Куб числа n — это n³ = n · n · n. Нужны при работе с объёмами, формулами суммы и разности кубов, кубическими уравнениями.

Формула суммыa³ + b³ = (a+b)(a² − ab + b²)
Формула разностиa³ − b³ = (a−b)(a² + ab + b²)
Пример12³ = 1728, 20³ = 8000.

Степень aⁿ — произведение n множителей, равных a. Строка — основание, столбец — показатель. a⁰ = 1 для любого a ≠ 0.

a \ n 012 345 678 910
ПримерСтрока 2, столбец 10 → 2¹⁰ = 1024.
Свойствоam · an = am+n; (am)n = amn.
Осторожно00 не определено; a0 = 1 только при a ≠ 0.

Таблица 07
Формулы сокращённого умножения
8
формул

Формулы сокращённого умножения — ключ к преобразованию выражений и разложению многочленов на множители. Работают в обе стороны: раскрытие скобок и свёртка.

Квадрат суммы
(a + b)2 = a2 + 2ab + b2
Квадрат разности
(a − b)2 = a2 − 2ab + b2
Разность квадратов
a2 − b2 = (a − b)(a + b)
Куб суммы
(a + b)3 = a3 + 3a2b + 3ab2 + b3
Куб разности
(a − b)3 = a3 − 3a2b + 3ab2 − b3
Сумма кубов
a3 + b3 = (a + b)(a2 − ab + b2)
Разность кубов
a3 − b3 = (a − b)(a2 + ab + b2)
Квадрат трёхчлена
(a + b + c)2 = a2 + b2 + c2 + 2ab + 2bc + 2ca
СоветУчите формулы в обе стороны — так вы и раскроете скобки, и увидите готовый шаблон в выражении.
ПрименениеРазность квадратов используется в сокращении дробей и в избавлении от иррациональности.
Осторожно(a + b)2 ≠ a2 + b2 — частая ошибка.
